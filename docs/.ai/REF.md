# References & Methodological Citations

- **Alphalens (Quantopian)**: Factor analysis tools for quantitative finance (IC, Information Ratio, Quantile Returns).
- **mRMR (Peng et al., 2005)**: Feature selection based on mutual information: criteria of max-dependency, max-relevance, and min-redundancy.
- **Boruta (Kursa & Rudnicki, 2010)**: Feature selection with the Boruta package using Random Forest shadow features.
- **SHAP (Lundberg & Lee, 2017)**: A unified approach to interpreting model predictions via Shapley Additive Explanations.
- **Stability Selection (Meinshausen & Bühlmann, 2010)**: High-dimensional variable selection through subsampling.
- **XGBoost (Chen & Guestrin, 2016)**: A scalable tree boosting system.
- **LightGBM (Ke et al., 2017)**: A highly efficient gradient boosting decision tree.\n
